## 驗證範圍與不能聲稱的事

- 單元／React hook／route 與 SQL synthetic fixtures 不代表已在 production 執行攻擊或破壞性還原。
- 所有測試使用合成帳號、合成密碼、合成媒體；沒有為測試刪除實際使用者或重設全站登入。
- 未在真瀏覽器完成所有播放器媒體相容性、裝置 storage quota、螢幕閱讀器及多連線 DB 負載測試；這些是發布觀察項，不以單元測試冒充。
- 本分支保留安全廣告過濾、signed danmaku、成人／來源限制、傳統中文與現有播放功能。
- 上游 main 合併、正式部署、production backup/restore 執行均不因這份文件而自動授權。

## 部署前資料庫前置條件

本版需要依順序安裝 `002_atomic_kv.sql`、`003_server_only_kv_permissions.sql`、`004_atomic_delete_user.sql`、`005_registration_session_generation.sql`。安裝必須先核對目標、備妥回復方式並取得適當批准；檢查 invoker／private EXECUTE ACL、固定表名、RLS 及 service CRUD，確認 install-only 變更前後資料筆數一致。具體環境的安裝與驗證紀錄不包含在公開程式碼文件中，請參閱各自的私有操作紀錄。

## 應用回退限制

新程式會將新註冊／改密碼憑證寫成帶 generation 的 envelope。原始基準 `997caa8` 只讀字串密碼，不能在已有新 envelope 後直接回退並假設帳號仍可登入。應保留本分支的 credential reader、signed sessionVersion 驗證與原子 RPC 呼叫作為安全相容底線，針對其他功能 forward-fix／回退；不要為回退把憑證批次降回字串，這會撤銷逐帳號版本保護。單獨撤銷 SQL function 也不能當作完整應用回退。
